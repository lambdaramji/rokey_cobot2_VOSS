# 정의석 기술스택 및 아키텍처

## 1. 목적

이 문서는 VOSS 프로젝트에서 정의석 담당 영역의 기술스택과 역할 분담을 정리한 기준 문서다.
앞으로 웹/HMI, 백엔드, AI/Voice, DB, ROS-Web 연동 관련 구현과 문서화는 본 구성을 기준으로 한다.

---

## 2. 핵심 기술스택

| 영역 | 기술스택 | 역할 |
|---|---|---|
| Frontend | React + TypeScript + Vite | Web HMI, 상태/이력/통계 화면 |
| Backend | Java 21 + Spring Boot | 메인 웹 백엔드, REST API, 비즈니스 로직, DB 연동 |
| Database | PostgreSQL | 로그, 이력, 집계, 업무 데이터 저장 |
| Realtime / Web | REST API + SSE | 일반 API 통신 및 Spring Boot → React 실시간 상태 전달 |
| AI / Voice | Python 3.12 + FastAPI + OpenAI API + Whisper | STT, LLM Intent 분석, AI/Voice 처리 |
| ROS | ROS 2 Jazzy + rclpy + CycloneDDS | 로봇·비전·음성 노드 통신 |
| Messaging | MQTT + Mosquitto | ROS 2 ↔ Web 시스템 메시지 브리지 |
| Infra | Docker + Docker Compose + Nginx + GitHub Actions | 실행 환경, 배포, Reverse Proxy, CI/CD |

---

## 3. 역할 분담

### React + TypeScript + Vite

- Web HMI 구현
- 로봇/작업 상태 표시
- OCR/분류 결과 표시
- 로그·이력·통계 조회
- Spring Boot REST API 호출
- Spring Boot SSE 구독

### Spring Boot

Spring Boot를 **메인 웹 백엔드**로 사용한다.

- REST API 제공
- 비즈니스 로직 처리
- PostgreSQL CRUD
- 작업 이력 및 통계/집계 제공
- HMI용 데이터 제공
- SSE를 통한 실시간 상태 전달
- FastAPI AI 서비스 호출 및 결과 연동

### FastAPI

FastAPI는 **AI / LLM / Voice 전용 서비스**로 사용한다.

- Whisper 기반 STT
- OpenAI API 호출
- 자연어 명령 분석
- LLM Intent 추출
- Structured Output 처리
- AI/Voice 관련 Python 라이브러리 연동

FastAPI는 일반 웹 CRUD나 메인 비즈니스 로직의 주체로 사용하지 않는다.

### PostgreSQL

- 분류 결과 로그
- 작업 이력
- 보류/실패 이력
- 처리 수량
- 집계/통계 데이터
- 필요한 업무 데이터

### ROS 2

- 로봇 제어 노드
- Vision 노드
- Voice 관련 ROS 노드
- Manager 노드
- 시스템 내부 Topic / Service / Action 통신

### MQTT + Mosquitto

- ROS 2와 Web 영역 간 메시지 전달
- ROS/Web 시스템의 느슨한 결합
- 상태, 결과, 명령 관련 메시지 브리지

### SSE

- Spring Boot → React 단방향 실시간 전송
- 현재 작업 상태
- 분류 결과
- 카운트/통계 변화
- HMI 갱신 데이터

## 5. 핵심 설계 원칙

### 5.1 Spring Boot와 FastAPI의 경계

Spring Boot와 FastAPI를 데이터의 정적/동적 여부로 구분하지 않는다.

```text
Spring Boot = Web / Business / DB의 중심
FastAPI     = AI / LLM / Voice 전용
```

실시간 데이터도 웹/HMI에 필요한 경우 Spring Boot가 SSE를 통해 전달할 수 있다.
FastAPI를 사용하는 이유는 실시간 데이터 때문이 아니라 Python AI 생태계를 분리하기 위해서다.

### 5.2 LLM의 역할

LLM은 사용자의 자연어 명령을 해석하고 구조화된 Intent로 변환한다.
실제 DB 처리나 시스템 명령 실행은 Spring Boot 또는 ROS 2의 담당 컴포넌트가 수행한다.

예시:

```text
"역삼동 지금까지 몇 개 처리했어?"
        ↓
FastAPI + LLM
        ↓
{
  "intent": "query_history",
  "region": "역삼동"
}
        ↓
Spring Boot
        ↓
PostgreSQL 조회
        ↓
React / Voice 응답
```

### 5.3 Web과 ROS의 경계

브라우저가 ROS 2에 직접 연결하지 않는다.
ROS 2와 Web 영역은 MQTT/Mosquitto를 통해 연결한다.

```text
ROS 2 ↔ MQTT Bridge ↔ Mosquitto ↔ Web Backend
```

## 6. Infra / DevOps

### Docker / Docker Compose

- Spring Boot
- FastAPI
- PostgreSQL
- Mosquitto
- Nginx

등의 실행 환경을 일관되게 구성한다.

### Nginx

- React 정적 파일 제공 또는 프론트엔드 Reverse Proxy
- `/api` → Spring Boot
- 필요 시 `/ai` → FastAPI
- 배포 환경의 단일 진입점 역할

### GitHub Actions

- Build
- Test
- CI/CD
- Docker 이미지 빌드/검증

에 사용한다.

---

## 7. 한 줄 설명

> VOSS의 웹 시스템은 React와 Spring Boot를 중심으로 구성하고, PostgreSQL로 업무·이력 데이터를 관리하며, Python AI 생태계가 필요한 Whisper와 LLM 기능은 FastAPI로 분리한다. ROS 2와 Web은 MQTT/Mosquitto로 연결하고, Spring Boot에서 SSE를 통해 React HMI에 실시간 상태를 전달한다.
