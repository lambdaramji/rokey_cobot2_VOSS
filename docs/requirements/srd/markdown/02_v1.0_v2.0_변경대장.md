# VOSS SRD v2.0 (잠정) — v1.0 → v2.0 변경 대장

**작성:** 2026-10-16(KST) · **기준:** main `fe11ded`, BRD v1.7 레포판(PR old#166), SRD v1.0(`archive/v1.0/`)

SRD v1.0 의 요구사항 카드 70장이 v2.0 에서 어떻게 바뀌었는지, 새로 붙은 26장이 무엇인지를 한 표로 정리한다. 본문(01)의 각 카드 'v2.0 변경' 줄과 같은 내용이며, 바뀐 요구 문장은 이전 문장을 함께 적는다. ID 는 삭제·재사용·폐기하지 않았다(§9.2).

## 1. 작성 방침 (작성자 결정 2026-10-16)

| # | 방침 |
|---|---|
| U1 | 신규 카드 단계 **S2**(Sprint 2 게이트 통과 기능만 수락 대상) |
| U2 | 요구 문장 = 현재 승인값, 코드·현장 값이 다르면 카드 '상태'에 적고 TBD 로 연결 |
| U3 | 미구현·시연 제외 요구는 카드·VT 를 남기고 상태로 표시, §8.4 "v2.0 기준 미수락" |
| U4 | TR-SERVO-01 → SDD, TR-SERVO-07 → 본문 §8.5 (카드 없음) |
| U5 | TR-PAL-12 → SYS-FR-032 에 흡수, SYS-FR-051 예약 |
| U6 | 레포 밖 증거·보고값은 '검증(밖·보고)'로 구분 |
| U7 | v1.0 보관본의 옛 링크는 그대로, v2.0 근거 번호에 `old#`/`_2#` |
