# VOSS SRD v2.0 (잠정) — 남은 결정·구현·실측 대장

**작성:** 2026-10-16(KST) · **기준 시점:** main `fe11ded`, 10/15 시연 뒤

v1.0 의 F-01~16 을 기준 시점 증거로 다시 판정하고 F-17·F-18 을 더했다. 값 충돌·미정 결정은 TBD-027~035(본문 §10)에 있고, 여기에는 실행 항목(누가 무엇을 해서 어떤 증거를 남기는가)만 둔다. '종결 제안'은 근거가 있어 닫아도 된다고 보는 항목이며 PL·담당자 확인 뒤 닫는다. v1.0 판은 `archive/v1.0/markdown/03_남은_결정_구현_실측_대장.md`.

## 2. 실행 대장

### F-01 — 동적 좌표·촬영/pose 정합 (종결 제안)

- 할 일/완료 증거: 핸드아이·이동 중 position_valid·pose 정합을 검증하고 ≤ 5 mm 제안값을 확인한다.
- 기준 시점 증거: 핸드아이 T16 최대 4.56 mm, 이동 중 좌표 최대 2.73 mm(지연 60 ms 보정)·`moving_verified`, pose_lag 0, G0·G1·시연이 HAND_EYE 로 동작 [레포: measurements-1008 #4·#5, measurements-1010 #10]
- 남은 것: ≤ 5 mm 는 승인 목록 밖 제안값으로 남는다. J6 회전 시 오차는 SYS-SF-006.
- 연결: SYS-FR-007, TBD-002, MC-001·002·004·010

### F-02 — 실제 제어 API·최신 목표·동시성 (종결 제안)

- 할 일/완료 증거: 두산 서보 명령 경로와 적용 주기·큐 경쟁을 확인한다.
- 기준 시점 증거: speedl_stream 결정(ADR-0010, pending #8), 단위 mm/s 실로봇 확인, gateway 큐 30.4분 78/78·64.5분 FAULT 0 [레포: measurements-1006 #3, measurements-1008 #15, measurements-1010 #9]
- 남은 것: pose 5초 창 45 Hz 미달 사례의 10/11 개선 뒤 재측정(SYS-CT-003).
- 연결: SYS-CT-003, TBD-014

### F-03 — 파지 방향·폭/힘/높이·안전 인계 (종결 제안)

- 할 일/완료 증거: 31 mm 폭 파지 근거(ADR-0009)와 39 mm·14 N·보고 폭 시험.
- 기준 시점 증거: ADR-0009, T34 시험(measurements-1008 #14), VERIFY 24회 grip True·폭 40.6~41.5 mm, G1 20/20 [레포]
- 남은 것: 벨트 사전 개방 50/90 mm 는 TBD-027 로 분리했다.
- 연결: SYS-FR-009·010, TBD-015

### F-04 — 기본 stop·입력 상실·limit (남음)

- 할 일/완료 증거: stop 호출 주체·순서·멱등, watchdog, 정지 지연·거리 실측.
- 기준 시점 증거: stop 멱등·manager 먼저 호출 → cancel → PAUSED 구현, 동시 stop 묶기(old#176), watchdog 0.2 s, 정지 20 mm/s 0.24 s·4.98 mm [레포: measurements-1010 #5·#12]
- 남은 것: 10/14 MoveToZone 450 mm/s 중 stop 응답 4/5 TIMEOUT 원인(`_2#50`), IDLE 중 stop 이 IDLE 에 머무는 동작을 표에 반영할지(v1.0 표는 "모든 상태 → PAUSED").
- 연결: SYS-SF-001, TBD-017, F-17

### F-05 — 초기 설정·ready·기동 (진행)

- 할 일/완료 증거: 설정 sha 기록, ready 판정, 기동 절차.
- 기준 시점 증거: ROBOT ready = RobotState, 노드별 config sha 일치 기록, 레포 config 승격, 기동 프로필 `scripts/voss_up.sh`
- 남은 것: VISION·OCR heartbeat 없음(인터페이스 변경 필요), 기본 경로 통일 일부 노드만, TCP 미등록 처리(TBD-034).
- 연결: SYS-FR-001·033, TBD-006·018

### F-06 — 적재 후 복귀 실패의 업무 결과 (남음)

- 할 일/완료 증거: RETURN_FAILED 일 때 manager 의 최종 outcome/reason 결정과 구현.
- 기준 시점: 제안 상태(src/voss_manager/CLAUDE.md). slot 은 개방 시(placed_stamp≠0) 증가로 확정.
- 연결: SYS-FR-034, TBD-007

### F-07 — 격자·용량·RECHECK 점유 (진행)

- 기준 시점 증거: A·B·C 3×2×2층·RECHECK·HOLD 2×1 구현, 구역 가득이면 PAUSED → reset_zone, 시연 칸 0~6 사용
- 남은 것: ZONE_FULL 결과 기록(PASSED + reason ZONE_FULL 제안) 미구현.
- 연결: SYS-FR-012, TBD-016

### F-08 — 정상 DB commit·조회·로그 대조 (종결 제안)

### F-17 — 시연 속도 stop·멈춤·재개 (신규)

- 할 일/완료 증거: 구역 이동 300 mm/s 와 팔레타이징 중 "멈춰"·HMI 정지 → PAUSED → 재개를 실기로 확인하고, 10/14 450 mm/s stop 응답 TIMEOUT 원인을 정리한다. 실로봇 실행은 사람이 비상정지 옆에서 한다.
- 기준 시점: 시연 2회차 PAUSED 0, ADR-0014 조건 ②의 멈춤·재개 미확인.
- 연결: SYS-FR-019·042, SYS-SF-001, F-04

### F-18 — 팔레타이징 실패 경로 실기 (신규)

- 할 일/완료 증거: 파지 재시도, 구역 위층 박스 3회 실패 → FAILED + PAUSED → 치운 뒤 재개(재개 위치는 TBD-029), 팔레트 1층 FAILED 뒤 당겨 놓기, ListPlacements 실패 시 미시작, 경로 제외(EXCLUDED)가 나는 경로, C 트레이 집기 순서(R-31), 원래 구역 칸 비움 처리와 완료 안내 숫자를 실기 또는 기록된 시험으로 확인한다.
- 기준 시점: 단위 시험(`test_pallet_fsm.py` 등)만, 실기 기록 없음.
- 연결: SYS-FR-037·039·043·044, SYS-DT-004, TBD-029
