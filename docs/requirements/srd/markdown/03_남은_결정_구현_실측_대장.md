# VOSS SRD v0.4 — 남은 결정·구현·실측 대장

**작성:** 2026-10-07(KST). 6 개 상호 확인 이슈 종료 후 남은 작업을 정리했다. 날짜는 회신 계획/목표이며 새로 확정한 제출 마감이 아니다. 원래 TBD/MC ID를 유지한다.

## 먼저 정합할 상세

1. **RETURN_FAILED:** 적재 후 복귀 실패를 gateway가 구분하는 규약은 합의했다. manager의 최종 outcome/reason과 slot 점유 처리는 현지·학민의 결정이 필요하다. PLACED+RETURN_FAILED는 검토 예시이며 여기에서 확정하지 않았다.
2. **HOLD/RECHECK 용량:** 최신 물리 2칸과 최종 회신의 ‘누적 최대 3’ 표기를 정합해야 한다. ABC는 3칸을 기본으로 사용하며, 2칸 구역에는 존재하지 않는 slot을 지정하지 않는다.
3. **파지 조건:** 파지 방향은 31 mm 폭 파지로 결정됐고(pending #16, #70) BRD v1.3(#79)에 반영됐다. 남은 것은 근거 ADR-0009와 39mm/14N/검증 폭의 T34 10회 시험이다.
4. **로그/질문/세션:** manager 결과 로그의 제공·형식, 같은 box의 늦은 답 수락 창, SortState.session_id와 첫 결과 전 현재 세션 전달이 남는다.
5. **stop 계약:** `/voss/robot/stop`(Trigger) 이름은 합의됐으나 main에 없다. manager(#50)와 servo(#53)가 모두 부르는 회신이 있어 호출 주체·순서·중복 호출 허용을 F-04에서 정한다.
