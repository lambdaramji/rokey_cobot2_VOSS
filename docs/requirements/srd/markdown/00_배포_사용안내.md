# VOSS SRD v2.0 (잠정) — 배포·사용 안내

**작성일:** 2026-10-16(KST) · **기준:** BRD v1.7 레포판(PR old#166) · main `fe11ded`(2026-10-15 19:21) · 기준 시점 2026-10-16

SRD v1.0(10/07, BRD v1.3 기준)을 Sprint 2 와 10/15 시연 뒤의 상태에 맞춰 개정한 판이다. ISO/IEC/IEEE 29148:2018 SyRS 참고 구성과 v1.0 의 장 구조·ID 를 유지하고, Sprint 2 요구를 새 ID 로 붙였으며, 요구사항마다 기준 시점의 구현·검증 상태와 증거를 기록했다.

**잠정 상태:** 작성자 검토 중이며 팀 기준선 승인(PL)과 담당자 확인 전이다. 확정 절차는 본문 부록 A. 확정해 올릴 때 "(잠정)"을 뗀다.

## 주의

- 상태는 증거가 있는 것만 '검증'으로 적었다. 레포 밖 원본·현장 보고값은 '검증(밖·보고)'로 구분했다. 수행하지 않은 시험을 통과로 적지 않았다.
- 요구 문장은 현재 승인값(BRD v1.7·ADR·PL 결정)이다. 코드·현장 값이 다르면 카드 '상태'에 적고 TBD-027~035 로 연결했다.
- 다른 파트 담당 카드(팔레타이징·음성 기동·상태기계·계약)는 레포 문서와 코드로 썼고 담당자 확인 전이다.
- 그림(배포·논리 구성도)은 자리만 있다(본문 부록 F).
- PR·이슈 번호는 `old#n`(lambdaramji 레포)·`_2#n`(임시 레포)을 구분해 적었다(ADR-0015).
