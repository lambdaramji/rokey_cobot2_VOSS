# VOSS SRD v2.0 (잠정) — BRD v1.3 → v1.7 대조 기록

**작성:** 2026-10-16(KST) · **기준:** BRD v1.7 레포판(`docs/requirements/VOSS_BRD_v1.7.docx`, PR old#166), README "v1.7 이후 바뀐 값"(main `fe11ded`)

SRD v1.0 은 BRD v1.3 기준이었다. 이 기록은 v1.3 → v1.7 을 ID 단위로 대조해 SRD v2.0 이 무엇을 반영해야 하는지 정리한 것이다. v1.1 ~ v1.3 대조는 `archive/v1.0/markdown/05_BRD_v1.1_v1.2_대조기록.md` 에 있다.

- 비교 원문: 레포의 `VOSS_BRD_v1.3.docx`·`VOSS_BRD_v1.7.docx`, git 기록의 v1.4(`08b7675`)·v1.5(`89375b7^`) docx 를 표준 라이브러리 XML 로 텍스트 추출해 비교했다(추출 방식 차이 없음 확인). v1.7 Markdown 사본(`VOSS_BRD.md`)과 핵심 문자열 12개가 같다. 변경표 `BRD_v1.5_to_v1.7_변경표.md` 를 함께 봤다.
- 판 표기: v1.6·v1.6.1 docx 는 없다. v1.6·v1.6.1·v1.7 은 v1.7 본문의 괄호 표기 `(v1.6)`·`(v1.6.1)`·`(v1.7)` 와 변경표로 구분했다. 표기 없는 v1.5 → v1.7 차이는 "v1.6~v1.7(표기 없음)"으로 적었다.
- 1~9장 ID 행은 v1.3 → v1.4 → v1.5 사이에 바뀐 것이 없다. 1~9장 ID 변경은 모두 v1.6·v1.7 에서 생겼다.
- 유형: 동일(행 텍스트 같음) · 문구만(수치·조건·동작 같음) · 의미 변경(수치·조건·동작·상태 바뀜) · 신규(v1.3 에 없음) · "동일(본문)·10.12 대체"(행은 같지만 10.12 대체표가 값을 바꿈).
- SRD 반영: 의미 변경·신규 ID 가 어느 SYS 카드로 갔는지는 본문 §9.3, 카드별 변경은 02 변경 대장.
