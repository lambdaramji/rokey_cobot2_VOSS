요구사항·ID·인터페이스/검증 카드의 수정·추가·삭제는 반드시 해결할 문제에 한해 신중히 제안합니다. 기존 행과 ID는 지우거나 재사용하지 않고 수정/삭제 제안으로 표시합니다. ID 변경은 이전→새 ID 대응을, 추가 항목은 담당별 임시 ID를 남깁니다. 관련 담당자 확인·PL 검토 후 병후가 확정 SRD에 반영합니다.

## 회신·상태 관리

- [ ] 모든 해당 MC-ID에 공동 답변 또는 미정 이유·담당·예정일을 남겼다.
- [ ] 두 사람의 확인 이름·일시와 실제 데이터 예시/증거를 남겼다.
- [ ] A 최소와 B 후속, C 채택 상태를 나눴다.
- [ ] 다자 계약의 추가 확인과 후속 구현/실기 작업은 연결된 MC-ID·기존 작업 이슈에 기록했다.

이 조합의 회신을 받으면 병후가 체크를 갱신합니다. 해당 조합의 확인 작업을 종료해도 다자 계약의 전체 승인·실측·G0/G2 수락 상태는 상위 #6에 따로 남깁니다. 해결되지 않은 필수 계약은 담당/기한/후속 이슈를 명시해 계속 추적합니다. 정상 자동 사이클과 예외 처리를 나누고 작업자 대기는 별도 기록합니다.
