# VOSS SRD v0.2 — 추가 자료·결정·취합 이후 순서

**확정 일정(KST):** 상호확인 회신 2026-10-06 18:30까지 · 첫 실기 실험/실측 2026-10-07까지 · 실제 1박스 전체 흐름 **G0 통과 목표 2026-10-10까지**. 구체 장비 시간·검토 방식·수락 확인자는 별도 확인한다.

**일자:** 2026-10-06 KST · **목적:** 상호 확인 답변으로 남은 SRD를채우기

## 1. 병후님이 지금 할 일

1. 00 안내·01 SRD를 공통 참고로, 03~08 상호확인서를 해당 두 사람에게 배포한다. 본인이 참여하는 03·06·07은 현지·학민·의석과 직접 확인한다. 회신 마감은 **오늘 18:30 KST**다.
2. A 계약부터 닫는다. 좌표/촬영 시점 pose(MC-001·002·004·010), 실제 명령/파지/정지(MC-011~014), 액션/인계(MC-005·006), 설정/준비/적재 결과(MC-009·016·019), DB 키/스키마/commit(MC-003·020·027)을 먼저 확인한다. B 후속과 C는 상태를 따로 남긴다.
3. 같은 MC-ID의 공동 답변을 02 대장에 모아 비교한다. 여러 조합이 연결되면 모든 영향 담당자가 하나의 최종 규약을 수용했는지 확인한다. 불일치하면 미정 이유·담당·예정일을 남긴다.
4. 합의된 규약과 실측값을 해당 SRD 본문·IC·VT·TBD에 반영한다. 요구사항 변경은 기존 ID·변경 전후·필수 이유·영향과 PL 검토·증거를 기록한다.
5. 확정한 docs/interfaces·voss_msgs·config·ADR·생산/소비 노드를 같은 버전으로 동기화하고 rebuild·배포·연결 검증한다. 이번 작업은 문서 취합까지이며 저장소 코드는 변경하지 않았다.
6. 준비·안전·필수 계약을 확인한 뒤 사람이 실제 장비로 실험한다. **첫 실기 실험·실측 목표는 10/07까지, G0 통과 목표는 10/10까지**다. G0 수락은 같은 박스의 인식·이동 중 픽업·적재·DB commit/조회·복귀가 모두 확인될 때만 기록한다.
7. G0 이후 B 필수 시나리오·성능·장애 시험을 완성하고 PL 검토·기준선 승인을 받는다. C는 G0 이후 채택 판단과 별도 시험을 진행한다.
