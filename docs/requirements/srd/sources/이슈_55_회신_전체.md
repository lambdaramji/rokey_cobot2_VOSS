스택 기준은 ADR-0006(제안, PR #62)입니다. ADR 번호는 #57의 `0005-rg2-modbus-direct`와 겹치지 않게 0006으로 잡았습니다.

### MC-019 — 로봇 상태 원천
- **판정:** 합의 (FR-001 주담당 남현지, gateway는 상태 제공)
- **의석 측 소비:** hmi_bridge가 학민 님이 제안한 `/voss/robot/state`를 구독해 MQTT `voss/robot`(QoS 0, 비retained)으로 내보내고, HMI에 표시합니다. 값을 받지 못하면 `UNKNOWN`으로 표시합니다.
- **확인 요청:** `/voss/robot/state`의 타입·필드·주기를 정해 주세요. HMI에서 보여 주려는 항목은 아래와 같습니다.
  - 연결 상태: `CONNECTED / DISCONNECTED`
  - 모드: `READY / MOVING / ERROR / ESTOP`
  - 현재 동작: `move_to_zone` 진행 중인 구역
  - 그리퍼 폭
  - 오류 코드·문구
  - 주기: 1~2 Hz면 충분합니다.

### MC-026 — MQTT 네트워크 조건
- **판정:** 합의 (JSON·QoS·ack 표는 #52 MC-026)
- **네트워크 제안:**
  - Mosquitto는 공용 PC 호스트, `listener 1883 0.0.0.0`, `allow_anonymous false`(비밀번호는 `.env`)입니다. Spring Boot는 같은 호스트(`--network host`)에서 `localhost:1883`로 붙습니다.
  - 브라우저는 공용 PC의 Nginx(80)로만 접속합니다. 개인 PC에서는 Wi-Fi(`wlo1`, Rokey_A)로 `http://<공용 PC wlo1 IP>/`에 접속합니다.
  - **로봇망(`enp4s0`, 192.168.1.0/24)에는 웹·MQTT 트래픽을 보내지 않습니다.**
- **확인 요청:**
  - 공용 PC에 방화벽(ufw)이 켜져 있으면 80과 1883 허용이 필요합니다.
  - Rokey_A에서 단말끼리 통신이 되는지(AP 격리 여부) 확인 부탁드립니다. 막혀 있으면 HMI를 공용 PC 화면에서만 씁니다.

### MC-028 — 공용 PC 사양·GPU
- **판정:** 합의 — 기본 사양은 PR #60에 실측 근거가 있습니다(정의석 08:55 확인, 학민 님 오후 갱신: dialout, D435i 5000M). 고맙습니다.
- **남은 것:**
  - GPU 컨테이너 실행 시험 `docker run --rm --gpus all ros:jazzy-ros-base-noble nvidia-smi`, USB 포트 육안 확인: 정의석, 10/07 오전. 사람이 실행합니다.
  - 동시 부하 시험(비전 + Whisper): 10/08, 남현지·정의석.
- **자원 메모:** 컨테이너가 3개 늘어납니다(ai: GPU, web·db: CPU). web·db에는 메모리 상한을 둡니다(제안 Spring 1 GB, PostgreSQL 512 MB). VRAM은 Whisper와 비전만 씁니다.
- **마이크:** 학민 님이 지적한 BRD "USB 마이크" vs 배포 "내장 마이크" 차이는 내장 DMIC를 기본으로 하고, #17 1 m 시험 결과로 하나로 맞춥니다. USB 포트가 빠듯해서(#5 5번) USB 마이크는 마지막 수단으로 둡니다.

### MC-029 — 호스트/컨테이너·DDS NIC
- **판정:** 일부 합의 → 배포 표 제안
- 웹·DB 스택은 ADR-0006(React + Spring Boot + FastAPI + PostgreSQL)으로 제안해 두었습니다. PL 승인 대기 중입니다.

| 구성요소 | 위치 | 포트 | 네트워크 | 담당 |
|---|---|---|---|---|
| Mosquitto | 호스트 | 1883 | 호스트 | 정의석 (설치·설정 — 학민 님 확인) |
| 음성 3노드, hmi_bridge, sort_logger | 호스트 (ROS) | — | DDS `lo` | 정의석 |
| FastAPI (Whisper·OpenAI) | `docker/ai` (GPU) | 8000 | `--network host` | 정의석 |
| Spring Boot | `docker/web` | 8080 | `--network host` | 정의석 |
| React + Nginx | `docker/web` | 80 | `--network host` | 정의석 |
| PostgreSQL | `docker/db` + 호스트 볼륨 | 5432 | `--network host` | 정의석 |
| 비전 | `docker/vision` (GPU) | — | `--network host`, DDS `lo` | 남현지 |

- **DDS `lo`:** 의석 측은 `lo` 그대로도 괜찮습니다. 웹·HMI는 DDS가 아니라 MQTT·HTTP로 붙기 때문입니다. `wlo1`을 추가할지는 학민 님 판단에 맡깁니다(개인 PC에서 `ros2 topic` 디버깅이 필요할 때만).
- **OpenAI 경로:** FastAPI는 `--network host`라 호스트 기본 경로(`wlo1`)로 나갑니다. #5 3번(유선 게이트웨이 192.168.1.1, metric 20100) 때문에 경로가 metric에 기대고 있습니다. 시연 전에 `ipv4.never-default yes` 적용을 권합니다(학민 님 결정).
- **확인 요청:** 두산 브링업·에뮬레이터·RG2 Modbus가 80/8000/8080/5432/1883 중 쓰는 포트가 있는지 확인 부탁드립니다. 겹치면 웹 쪽 포트를 바꾸겠습니다.

## 김학민 회신 — #55 김학민–정의석 (MC 4건)

작성: 김학민 · 2026-10-06 KST. [의석님 회신](https://github.com/lambdaramji/rokey_cobot2_VOSS/issues/55#issuecomment-6014686741)의 확인 요청에 답합니다. 의석님 안과 같은 부분은 "확인"으로만 적었습니다. 근거는 [#51 회신](https://github.com/lambdaramji/rokey_cobot2_VOSS/issues/51#issuecomment-6015052621)과 PR #60(공용 PC 원본 출력)에 있습니다.

### MC-019 — 로봇 상태 원천
- **판정:** 합의 — hmi_bridge가 `/voss/robot/state`를 구독해 `voss/robot`으로 내보내고, 받지 못하면 UNKNOWN으로 표시하는 것을 확인합니다.
- **`/voss/robot/state` 정의(제안, 의석님 표시 항목 반영):** `voss_msgs/RobotState`

| 필드 | 타입 | 의미 |
|---|---|---|
| `header` | std_msgs/Header | 발행 시각(공용 PC 시계), frame 없음 |
| `connected` | bool | 두산 컨트롤러·RG2 Modbus 연결이 모두 살아 있음 |
| `state` | string | READY / BUSY / STOPPED / STOP_UNCONFIRMED / ERROR (#50·#51에서 PL과 합의한 값) |
| `action` | string | 진행 중 동작. 예: `MOVE_TO_ZONE:B`, `SERVO`, `GRIPPER`, 없으면 빈 값 |
| `gripper_width_mm` | float32 | RG2 보고 폭(실제 간격 ≈ 보고값 − 10 mm) |
| `error_code` | string | 예: `ESTOP`, `SAFETY_STOP`, `GRIPPER_ERROR`, `TIMEOUT`, 없으면 빈 값 |
| `detail` | string | 사람이 읽을 문구 |

  - 의석님 모드와의 대응: MOVING → `BUSY`, ESTOP → `state=ERROR` + `error_code=ESTOP`. 비상정지·안전정지는 두산 로봇 상태 조회로 판별합니다(T32에서 실제 값 확인).
  - 발행: 상태가 바뀔 때 + 2 Hz, reliable + transient_local depth 1
- **남은 미정:** interfaces 문서 PR(김학민, 10/07). 필드가 부족하면 그 PR에 의견 주세요.

### MC-026 — MQTT 네트워크 조건
- **판정:** 합의 — Mosquitto는 호스트 1883, 브라우저는 Nginx 80, 개인 PC는 `wlo1`로 접속, 로봇망 `enp4s0`에는 웹·MQTT를 보내지 않는다는 안을 확인합니다.
- **확인 요청 답:**
  - ufw: 공용 PC에서 아직 확인하지 않았습니다. 10/07 오전에 `sudo ufw status`로 보고, 켜져 있으면 80·1883을 `wlo1`에서만 허용합니다.
  - Rokey_A AP 격리: 10/07 오전에 개인 PC에서 공용 PC `wlo1` IP로 ping과 `nc -zv <IP> 1883`을 시험해 결과를 여기에 남기겠습니다.

### MC-028 — 공용 PC 사양·GPU
- **판정:** 합의 — 의석님 정리(PR #60 근거, GPU 컨테이너·USB 육안 확인은 의석님 10/07)를 확인합니다.
- **추가:** D435i는 지금 꽂힌 USB 3 포트(Bus 002, 5000M)에 고정하고 허브를 쓰지 않습니다. 포트가 모자라면 아두이노와 마우스를 전원 허브로 옮깁니다.

### MC-029 — 호스트/컨테이너·DDS NIC
- **판정:** 합의 — 의석님 배포 표를 확인합니다. 저는 호스트 브링업·네트워크·도메인을 맡습니다.
- **포트 충돌(확인 요청 답):** 겹치는 포트가 없습니다.
  - 두산 컨트롤러 192.168.1.100:12345(원격), RG2 Modbus 192.168.1.1:502(원격). 공용 PC는 이 포트를 열지 않고 접속만 합니다.
  - 에뮬레이터(`dsr_emulator`)를 쓰면 로컬 12345를 엽니다(`run_drcf.sh`, `-p 12345:12345`).
  - ROS 2·CycloneDDS는 UDP 7400번대를 씁니다.
  - 80/8000/8080/5432/1883과 겹치지 않습니다. 10/07에 `ss -ltnp`로 실제로 열린 포트를 확인합니다.
- **DDS NIC:** `wlo1`을 추가하겠습니다. 웹·HMI는 MQTT라 필요 없지만, 개인 PC에서 노드를 띄워 공용 PC 로봇과 붙여 보는 개발·디버깅(ROS_DOMAIN_ID 30)에 필요합니다. 로봇망 `enp4s0`에는 넣지 않습니다. 컨테이너도 같은 `CYCLONEDDS_URI`를 마운트해 설정을 맞춥니다(10/07, 김학민).
- **never-default:** 동의합니다. `Wired connection 1·2`의 게이트웨이를 지우고 `ipv4.never-default yes`를 10/07에 적용한 뒤, OpenAI 접속과 로봇 ping을 같이 확인합니다.

- `voss_msgs/RobotState`(`header`, `connected`, `state`, `action`, `gripper_width_mm`, `error_code`, `detail`)를 그대로 받겠습니다. 상태가 바뀔 때 + 2 Hz, reliable + transient_local depth 1도 확인합니다.
