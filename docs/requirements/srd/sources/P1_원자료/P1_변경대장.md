### 2-3. P1 교차 확인에서 고친 것

- **TCP 미등록 MoveToZone**: ④·③은 "거부 구현"으로 봤으나 코드는 **등록 없음 = 플랜지 모드 이동(경고)**, 모르는 TCP 만 거부(`robot_gateway.py:955-966` 직접 확인). ② 판단이 맞음 → SF-002 '부분 구현', TBD-034.
- **NFR-03**: ③은 '미측정'이었으나 pending #18 에 실제 API 20/20(10/08) 기록 → '부분 검증'(거부 100 % 시험 기록 없음).
- **R-30**: BRD 본문 문제는 순서(R-31·32가 R-27 앞)뿐. 충돌은 ADR-0015 가 제안한 "레포 한 계정 위험 = R-30" 과 BRD R-30(3순위 로봇 시간)의 ID 겹침이고, 그 위험은 BRD 에 없음 → 다음 BRD 판 제안 사항(SRD 는 참조만).
- **"#50"**: measurements-1015·ADR-0014 의 "#50 실기"는 `_2#50`(v1.0 의 #50 상호 확인 이슈와 다름).
