# 통합 시나리오 (3가지 버전)

> **각도 기준**: 벨트를 **위에서 내려다볼 때**, 0° = 박스 긴 변이 벨트 진행 방향과 나란함. **+ = 반시계 방향, − = 시계 방향**으로 돌려 놓는다. 로봇도 같은 방향으로 손목을 돌려 잡는다. 단, +70° 를 넘는 박스(80°·90°)는 반대(시계 방향)로 돌려 잡는다.
>
> **세 시나리오 공통 규칙**
> - **음성은 늘 "헬로, 로키." 로 시작**하고, 스피커 안내가 끝난 뒤 말한다. 두 번 해서 안 되면 그 단계만 웹 버튼이나 웹 텍스트 칸으로 넘어가고, 기록표에 "대체"로 적는다.
> - **다음 박스는 앞 박스가 트레이에 놓이고 로봇이 관측 자세로 돌아온 뒤** 넣는다. 넣은 뒤엔 박스에 손대지 않는다.
> - 질문에 30초 안에 답이 없으면 "응답이 없어 보류 구역에 놓습니다." 와 함께 보류 구역으로 간다.
> - 질의는 **동 이름**으로 묻는다. "A구역 몇 개야?" 처럼 구역으로 물으면 시스템이 구역을 동으로 바꾸지 못해 "어느 동인지 말씀해 주세요." 로 되묻는다.

### 기능 번호

| 번호 | 기능 | 뜻 | 시나리오에서 하는 것 |
|---|---|---|---|
| ① | 웹 시작 | 웹 HMI 버튼으로 분류 작업을 시작하고, 이번 회차에 넣을 박스 수를 저장한다 | 시작 버튼 → 투입 예정 수량 20 저장 |
| ② | 정상 분류 | 송장을 읽어 동에 맞는 트레이에 놓는다 (역삼 → A, 대치 → B, 청담 → C) | 똑바로 놓은 정상 박스 |
| ③ | 재확인 (180°) | 송장이 거꾸로라 처음에 못 읽으면 재확인 칸에 내려놓고 위에서 다시 읽어 목적 트레이로 옮긴다 | 3번 박스 |
| ④ | 기울기 각도 (J6 회전 파지) | 비스듬히 놓인 박스를 따라가며 로봇 손목(J6)을 박스 각도만큼 돌려 잡고, 들어 올린 뒤 원래 각도로 되돌린다 | ±30°~±90° 박스 |
| ⑤ | 재확인 질문 → 음성 답 | 다시 읽어도 확실하지 않으면 로봇이 어느 동인지 묻고, 작업자가 음성으로 답한 동으로 보낸다 | 흐린 역삼 송장 — 시나리오 1 은 6번, 2 는 7번, 3 은 10번 |
| ⑥ | 음성 정지 · 재개 · 시작 | "멈춰"로 일시 정지, "작업 재개해"로 이어서 진행, "작업 시작"으로 전체 분류 확인 | 7번 앞 |
| ⑦ | 우선 분류 → 전체 분류 | "○○동부터 분류해"면 그 동만 집고 다른 동은 집지 않고 통과시킨다. "전부 구역별로 나눠줘"면 다시 모든 동을 분류한다 | 11~13번, 12번 통과 → 12′ 다시 넣기 |
| ⑧ | 보류 | 동을 판별할 수 없는 박스에 "보류해"라고 답하면 보류 구역에 놓는다 (30초 무응답도 보류) | 15번 판별 불가 |
| ⑨ | 음성 이력 질의 | 지금까지 처리한 수를 음성으로 묻고 로봇이 DB 기록으로 답한다 — 동별 적재 수, 보류 수 | "○○동 몇 개야?" · "보류 몇 개야?" |
| ⑩ | 웹 텍스트 명령 | 음성 대신 웹 화면 텍스트 칸에 명령·질문을 입력한다. 답은 웹 답장과 스피커로 나온다 | "역삼동 몇 개 있어?" · "박스 몇 개 남았어?" |
| ⑪ | 팔레타이징 | 말한 배송 순서대로 트레이 박스를 팔레트(16칸 2층)에 옮겨 싣는다. 마지막 배송지를 트럭 안쪽부터 싣고, 칸이 모자라면 초과분은 트레이에 남긴다. 경로에 없는 동은 싣지 않는다 | 20번 뒤, P1~P16 |
| ⑫ | 웹 화면 확인 | 웹 HMI 에서 실시간 상태·벨트 위 박스 위치·집계·팔레트 3D 배치도를 확인한다 | 1번 · 팔레트 계획 때 |
