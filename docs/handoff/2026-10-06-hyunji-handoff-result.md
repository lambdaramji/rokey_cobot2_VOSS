## 문서와 다르게 진행한 것

- **캘리브레이션 범위:** 관측 자세에서 화면 위쪽 절반(상류)은 로봇 도달 한계(`tip_belt_up`, TCP x ≈ −107)보다 바깥이라 터치할 수 없다. 남현지와 현장에서 확인한 뒤 9점을 화면 아래 절반에만 두었다.
- **위치 표시:** L자 대신 박스 하류 쪽 변 아래 이름 테이프 한 조각. C 줄은 벨트 가장자리에 붙여 재현했다.
- **터치 기준점:** `+` 표시 없이 라벨 중앙을 눈으로 맞췄다. 그리퍼는 완전히 닫고 OBS 와 같은 수직 자세.
- **bag 구성:** 박스마다 bag 을 나누지 않고 시나리오마다 하나로 찍었다. 박스 순서는 기록하지 않았다.
- **생략:** D(조명 변화), E(하강).
- **OBS 복귀 확인:** 터치 후 관절값 MoveJ 로 돌아와 C1 사진과 비교했다. 어긋남 1~2 px.
