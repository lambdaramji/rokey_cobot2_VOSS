# ADR-0003: 10/06 캘리브레이션은 벨트 평면 호모그래피로, 정식 핸드아이는 10/07

- 날짜: 2026-10-06
- 상태: 승인됨 (2026-10-06 오전 팀 합의, 남현지 기록)
- 결정자: 팀 (영향: 남현지 비전, 김학민 로봇 조작, 박병후 belt_servo)
- 관련: T16(#25), SR-FN-02, TR-PICK-01~04, BRD R-06, measurements #7

## 배경
- 핸드아이 캘리브레이션용 체커보드가 10/06 오전까지 준비되지 않았고, 오전 로봇 슬롯은 김학민의 T31(구역 좌표 실측)과 겹친다.
- 놓기(5구역)는 고정 좌표 교시로 끝나므로 카메라가 필요 없다. 카메라 변환이 필요한 곳은 벨트 위 박스 집기뿐이다.
- 벨트는 평평하고 박스 윗면은 벨트 + 27 mm 로 일정하다. 관측 자세가 고정이면 픽셀 → (x, y) 는 평면 호모그래피 하나로 정해진다.
- 벨트 진행 방향: 오른쪽 (상류 = 왼쪽, 로봇 쪽).

## 결정
- 10/06: 관측 자세에서 박스를 벨트 위 9곳(계산 6 + 검증 3)에 놓고 사진 + TCP 터치 posx 를 기록해 `config/belt_homography.yaml` 을 만든다. 스키마는 docs/interfaces/calibration.md.
- 터치는 그리퍼를 닫고 관측 자세와 같은 수직 자세로 한다(툴축 차이가 2° 넘으면 도구가 경고. 접촉점을 터치 자세마다 TCP 로 정규화하므로 기울기 자체는 오차가 아니다 — 10/06 관측 자세는 수직에서 0.93° 기울어 있다). ~~TCP 등록 여부와 무관하게 x, y 가 맞다~~ → **틀렸다**(#48 리뷰): TCP 오프셋 xy 가 약 3 mm 라 수직이어도 x, y 가 약 3 mm, z 는 약 247 mm 달라진다. 터치 기준점(TCP/플랜지)을 기록하고 도구가 접촉점으로 정규화한다.
- T16 완료 기준(검증점 오차 ≤ 5 mm, 제안값)은 검증점 3곳의 오차로 판정해 measurements #7 에 적는다.
- 정식 핸드아이(체커보드, 강의 3-2 절차 `handeye_calibration.py`)는 보드 준비 후 10/07 에 한다. ~~추종 중 3D 좌표가 필요할 때만 쓴다.~~ → 갱신 절 참고(이동 중 좌표 G0 필수).

## 고려한 대안
- 정식 핸드아이를 10/06 에: 모든 자세에서 유효하지만 보드가 없고 1~2시간이 들어 오전 슬롯에 못 들어간다.
- 깊이 사용: 규칙 4(깊이 금지), D435i 는 약 28 cm 이하에서 불안정.
- 호모그래피만으로 끝내기: B안 개루프와 A안 첫 접근은 충분하지만 카메라가 움직이는 추종 중에는 맞지 않는다 → 10/07 핸드아이로 보완.

- 위험: 벨트가 오른쪽으로 흘러 추종할수록 로봇 베이스에서 멀어진다 → 추종 구간 리치 확인(T31, 김학민). 상류(박스 투입 위치)가 로봇 쪽이라 NFR-10(투입 위치와 대기 위치 분리) 확인 필요.

## 갱신 (2026-10-06 저녁, SRD 상호확인 #50 MC-002·#51 MC-032)
- **이동 중 베이스 좌표도 G0 필수**로 바뀌었다. 호모그래피는 관측 자세의 초기 위치 획득용이고, 이동 중에는 정식 핸드아이 + 촬영 시각 pose 보간 + 박스 윗면 평면 교점으로 비전이 계산한다(BoxTrack.position_base, #65).
- 일정: 핸드아이 10/07, 이동 중 좌표 검증 10/08(정지 박스를 로봇 이동 중 관측해 위치 흔들림·오차 기록). 검증 전에는 `position_valid=false`.
- 운용 해상도 1920×1080. 9점은 화면 하류 절반에만 있어 상류는 외삽이다 — 검증 구간을 나눠 보고한다. 9점 z 편차를 x·y 정확도로 대신하지 않는다.
- #48 리뷰(박병후) 반영: 이 파일의 출력은 관측 박스 윗면 중심(접촉점) 좌표이고 TCP 목표가 아니다 — 목표는 belt_servo 가 계산. 변환은 box_tracker 가 `belt_plane.pixel_to_base_xy` 로 하고, 대응점 볼록 껍질(`calib_hull_px`) 밖은 외삽이라 `position_valid=false`. 대응점 4개일 때도 퇴화 배치(세 점 일직선)를 거부한다.

## 판정 (2026-10-07)
- 10/06 점(C1~C6, V1·V2) + 10/07 재측정(C7~C10, V3R·V4·V5)을 합쳐 계산. 측정 전에 정한 규칙(검증점 5곳 모두 ≤ 5 mm)으로 **합격, 최대 2.63 mm**. 10/06 V3(6.97 mm)는 사진·터치 사이 박스 이동으로 보고 V3R 로 대체 — 상세는 measurements-1006.md #7.
- 유효 범위는 벨트 방향 x −100 ~ +3 mm(약 103 mm, 4.8 cm/s 에서 약 2.1 s). 결과 파일 `config/belt_homography.yaml`.
