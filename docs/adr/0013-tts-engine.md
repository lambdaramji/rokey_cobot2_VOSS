# ADR-0013: TTS 엔진으로 OpenAI GPT-4o mini TTS 채택

- 날짜: 2026-10-10
- 상태: 제안됨 (구현 완료, ADR 리뷰 대기)
- 결정자: 정의석
- 관련 SR / pending-decisions #: SR-SW-13, SYS-FR-022, SYS-PF-005, VT-022, VT-049, pending #12, T10 #19
- 관련 문서: ADR-0006, `docs/interfaces/web_api.md`

## 배경

VOSS는 분류 시작, 작업 상태, 오류 및 사용자 질문을 한국어 음성으로 안내해야 한다.

`speech_out`은 `/voss/voice/say`를 받아 실제 음성으로 출력해야 하며, 음성 응답 성능 목표는 사용자 발화 종료부터 실제 소리 시작까지 3초 이내(SYS-PF-005 / VT-049)이다.

T10 구현에서는 한국어 음성 출력과 FIFO 순차 재생을 확인했으나, 전체 음성 루프의 3초 성능은 아직 실측하지 않았다.

## 결정

OpenAI `gpt-4o-mini-tts` 모델과 `coral` 음성을 채택한다.

- FastAPI `POST /ai/tts`에서 OpenAI TTS를 호출한다.
- FastAPI는 ADR-0006에 따라 `127.0.0.1:8000`에서만 제공하며 Nginx로 노출하지 않는다.
- 응답은 24kHz, 16-bit, mono, S16LE PCM 스트리밍을 사용한다.
- ROS 2 `speech_out`은 `/voss/voice/say`를 구독하고 FIFO 큐와 단일 워커로 안내를 순차 재생한다.
- PCM 출력은 공용 PC의 `aplay`를 사용한다.
- API 키는 `TTS_OPENAI_API_KEY`로 분리하고, 실제 값은 Git에 포함하지 않는 `.env`에서만 관리한다.
- TTS 실패 시 오류를 기록하며, 실패 때문에 다음 안내까지 중단하지 않는다.

상세 HTTP 요청·응답과 오류 계약은 `docs/interfaces/web_api.md`를 따른다.

## 고려한 대안

- **A. OpenAI TTS — 채택**
  - 장점: 한국어 음성을 생성할 수 있고, 기존 FastAPI·OpenAI 연동 구조를 활용할 수 있다.
  - 단점: 인터넷 연결, API 키, 사용 한도 및 요금에 의존한다.

- **B. 로컬 TTS — 미채택**
  - 장점: 외부 네트워크 없이 음성 생성이 가능하다.
  - 단점: 공용 PC의 실행 환경 구성, 음질 및 지연시간을 추가 검증해야 한다.

- **C. 고정 안내 문장 PCM 사전 생성·캐시 — 후속 검토**
  - 장점: 고정 문장은 네트워크 장애 시에도 출력할 수 있고 응답 지연을 줄일 가능성이 있다.
  - 단점: 문장 목록 및 캐시 갱신 관리가 필요하며 동적 문장을 모두 처리할 수는 없다.
  - 현재 T10 구현에는 캐시 기능이 포함되지 않았다.

## 결과

### 확인된 사항

- FastAPI pytest 27개, ROS 음성 모듈 pytest 9개 통과
- `/voss/voice/say`를 통한 한국어 실제 음성 출력 확인
- 2개 안내 문장의 FIFO 순차 재생 확인
- ROS 수신부터 첫 PCM 전달까지 예비 측정 3회: 1,860ms / 1,096ms / 1,265ms

첫 PCM 전달 시각은 실제 스피커 발화 시작 시각이 아니므로 VT-049 합격 근거로 사용하지 않는다.

### 위험과 대응

- **네트워크 장애·API 오류:** 현재 구현에서는 음성 안내가 실패할 수 있다. 오류 로그를 남기며, HMI를 통한 안내 확인은 전체 통합에서 검증한다.
- **API 키·요금:** 공용 PC의 `.env`에 키를 설정하고 접근 권한과 사용 한도를 관리한다. 시연 이후 키 교체·폐기 여부를 담당자가 확인한다.
- **시연장 Wi-Fi 문제:** 고정 안내 문장 PCM 캐시를 대응안으로 검토한다. 채택 및 구현 여부는 후속 결정이 필요하다.
- **응답 지연:** SYS-PF-005 / VT-049의 발화 종료 → 실제 음성 시작 3초 기준은 전체 루프에서 별도로 실측한다.

안전 정지 명령은 TTS 응답을 기다리지 않고 기존 로컬 정지 경로에서 처리한다.

### 영향 범위

- `docker/ai`: TTS 서비스 및 API 키 설정
- `src/voss_voice`: `speech_out`, FIFO 큐, TTS 클라이언트, 오디오 재생
- `docs/interfaces/web_api.md`: `/ai/tts` 계약
- `docs/pending-decisions.md`: pending #12 결정 기록
