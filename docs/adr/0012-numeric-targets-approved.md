# ADR-0012: 수치 목표 5개를 SRD v1.0 값 그대로 승인 (pending #4)

- 날짜: 2026-10-08
- 상태: 승인됨 (2026-10-08, 전원 Slack 투표 👍 4/4)
- 결정자: 전원 (남현지·김학민·박병후·정의석), 기록 PL 남현지
- 관련 SR / pending-decisions #: SYS-PF-001·002·003·004·009 (NFR-01·02·03·04·07), BRD 10장, pending #4. 게이트 기준은 pending #3·ADR-0002

## 배경
- pending #4(기한 10/06)는 SRD 10장 수치 목표의 팀 승인이다. 승인 전에는 각 문서·완료 기준에서 이 값을 "제안값"으로 적어 왔다(예: voss_servo `DESIGN.md`).
- 10/10 G1 게이트(70 %)와 10/15 시연(10개 중 8개) 판정이 이 값을 그대로 쓴다. 게이트 전에 확정해 둬야 판정 기준을 두고 다시 논의하지 않는다.
- 10/08 실측 기준으로 값을 바꿀 근거는 없었다. 정지 OCR 50/50(T18), box_tracker 검출 10/10 트랙·30 Hz(measurements-1008 #1·#8), 공용 PC CPU OCR 평균 2.06 s(박스당 2회, measurements-1008 #9)는 사이클 30 s 안에 든다.

## 결정
SRD v1.0 값을 바꾸지 않고 승인한다. 측정 방법·분모는 SRD 검증 카드(VT)를 따른다.

| 목표 | SRD | 값 | 측정 (VT) |
|---|---|---|---|
| 이동 중 픽업 성공률 | SYS-PF-001 | 재시도 포함 **≥ 70 %** | 20회 중 14회 이상, 분모 고정 (VT-045, `docs/g1-gate.md`) |
| 분류코드 OCR 정확도 | SYS-PF-002 | 전체 **≥ 90 %**, 흐린 송장 제외 **≥ 95 %** | 정지 50장(흐린 5 포함)·추종 50장 구분, 두 조건 모두 (VT-046) |
| 지시 해석 정확도 | SYS-PF-003 | **≥ 95 %** | 4종 × 5문장 = 20 중 19 이상, API 오류·timeout 도 분모 (VT-047) |
| 사이클 시간 | SYS-PF-004 | 정상 자동 처리 **≤ 30 s** | 박스 감지 → 적재 완료, 예외 처리 세트는 따로 기록 (VT-048) |
| 시연 최종 적재 | SYS-PF-009 | 서로 다른 박스 **10개 중 8개 이상** 올바른 구역 | 10/15 시연 (VT-067) |

- 이 5개는 이제 "제안값"이 아니라 **승인값**이다. 완료 선언은 여전히 공용 PC·현장 측정값으로만 한다.
- 목록 밖 수치(핸드아이 오차 ≤ 5 mm, 서보 루프 지연 100 ms, belt_servo `acc`·하강 속도 등)는 이 결정에 들어가지 않는다 — 각 ADR·설계 문서에서 따로 정한다.
- 게이트 미달 시 처리는 바꾸지 않는다: 자동 전환 없이 게이트 회의에서 ① B안 ② 범위 축소 ③ A안 10/12 연장 중 결정(pending #3, ADR-0002).

## 고려한 대안
- A: SRD 값 그대로 승인 — 문서·게이트 기록표가 이미 이 값으로 쓰여 있고, 10/08 실측이 값을 바꿀 근거를 주지 않았다. **채택.**
- B: 시연 전 실측을 보고 조정(예: 파지 60 %) — 기준을 측정 뒤에 낮추면 게이트 의미가 없어진다. 미달 대응은 범위 축소·B안으로 한다(ADR-0002).
