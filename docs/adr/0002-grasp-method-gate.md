# ADR-0002: 파지 방식 A안 기본, 10/10 게이트로 B안 전환 판단

- 날짜: 2026-10-05
- 상태: 제안됨 (10/06 승인 예정)
- 결정자: 전원
- 관련: SR-FN-03·04, BRD 8.2, pending-decisions #3

## 배경
폐루프 비주얼 서보(A)는 시연 가치가 높지만 손목 카메라 하나로 2주 안에 안정화하기 어렵다. 벨트 속도·방향이 일정해 개루프 동기 추종(B)이 폴백으로 성립한다.

## 결정
- 10/07~08 B안 베이스라인을 먼저 만들어 "벨트 위 박스 파지 1회"를 확보한다.
- 10/08~10 A안 구현. **10/10 게이트: 20회 중 14회(70%)** 미달이면 B안으로 전환하고 나머지 통합에 집중.
- 게이트 결과와 전환 여부는 이 ADR을 "승인됨/수정"으로 갱신해 기록한다.

## 결과
belt_servo 의 액션 인터페이스(`/voss/servo/track_and_grasp`)는 A·B 어느 쪽이든 동일하게 유지해 sort_manager 가 영향받지 않게 한다.
