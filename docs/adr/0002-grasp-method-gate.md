# ADR-0002: 파지 방식 A안 기본, 10/10 게이트로 B안 전환 판단

- 날짜: 2026-10-05
- 상태: 제안됨 — 2026-10-06 게이트 처리 문구 정정 (SRD 상호확인 #50·#53 MC-008, 박병후·남현지 합의)
- 결정자: 전원
- 관련: SR-FN-03·04, BRD 8.2, pending-decisions #3

## 배경
폐루프 비주얼 서보(A)는 시연 가치가 높지만 손목 카메라 하나로 2주 안에 안정화하기 어렵다. 벨트 속도·방향이 일정해 개루프 동기 추종(B)이 폴백으로 성립한다.

## 결정
- 폐루프 FF+P(A안)를 우선 구현한다(박병후). 개루프(B안)는 대안 후보로 남긴다.
- **10/10 게이트: 20사례 중 14회(70%)** 성능 점검은 유지한다. 로그 = 시도 번호·벨트 속도·결과·실패 원인.
- **날짜 도달이나 목표 미달만으로 자동 전환하지 않는다.** 미달이면 게이트 회의에서 로그·원인·개선 결과를 근거로 팀이 ① B안 개루프 ② 범위 축소(벨트 감속·여유 확대) ③ A안 10/12까지 연장 중 하나를 정한다. 결정자 전원, 기록 PL.
- speedl 미지원 같은 실행 경로 문제와 폐루프 성능 판단은 구분해 기록한다.
- 게이트 결과와 전환 여부는 이 ADR을 "승인됨/수정"으로 갱신해 기록한다.

## 결과
belt_servo 의 액션 인터페이스(`/voss/servo/track_and_grasp`)는 A·B 어느 쪽이든 동일하게 유지해 sort_manager 가 영향받지 않게 한다.
