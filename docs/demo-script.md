## 2. 박스 구성 (pending #19 — 제안 A, 전원 결정 전)
**왜 다시 짜나.** 분류 트레이는 A·B·C 각 3칸(9칸)이고 박스는 10개다. 그래서 1개는 A·B·C 밖(보류)에 있어야 한다. 단계 9 팔레타이징은 동별 3개 이하만 받는다(TR-PAL-03). 4단계 규칙 변경을 하든 빼든 구역마다 3개를 넘지 않아야 한다(넘으면 "구역 가득" → PAUSED).

| 박스 | 송장 | 넣는 단계 | 기대 결과 (4단계 없음) | 4단계 규칙 변경 있음 |

| 2 | S07-01 역삼동 | 2 → 통과·회수 → 3 재투입 | 2단계 PASSED(NON_TARGET), 3단계 A | A |
| 3 | S07-03 청담동 | 2 → 통과·회수 → 3 재투입 | 2단계 PASSED, 3단계 C | C |
| 4 | S07-01 역삼동 | 3 | A | A |
| 5 | S07-02 대치동 | 3 | B | B |
| 6 | S07-03 청담동 | 3 | C | C |

단계별 메모:
- **2단계** 통과 박스(2·3)는 벨트 끝 회수함에서 꺼내 3단계에 다시 넣는다. 다시 넣으면 새 box_id 가 붙고, 2단계의 PASSED 기록은 집계·팔레타이징 대상에서 빠진다.
- **5단계** 무효 답(후보가 아닌 동)은 1회만 다시 묻는다. 질문 중 "멈춰"는 타이머를 멈추고, "작업 재개해"는 다시 묻고 30 s 를 새로 잰다.
- **9단계**는 8단계 직후 RUNNING·처리 중 박스 없음에서 바로 받는다(벨트 위 박스가 없어야 한다). 팔레트가 비어 있지 않으면 거부하고 "reset_zone PALLET" 을 요구한다 — 시작 전 체크에서 비운다. 중간에 "멈춰" → "작업 재개해"는 남은 박스부터 이어 간다(든 박스는 그리퍼 보고 폭으로 확인 뒤 놓는다).
- 음성 인식이 안 되면 같은 명령을 HMI 버튼으로 내려도 된다(BRD 8.1).
