## 0. 부호와 용어 (이 문서 전체에 고정)

```
벨트 진행 방향(하류) ─────────────────────▶  (along 축 = belt.direction_base, D = (0.99992, −0.01292))
        ┌────────── 박스 46 mm 변 ──────────┐
        │ 뒤(상류)        중심 ●       앞(하류) │
        └─────────────────────────────────────┘
                              ▲ TCP(핑거 중심)가 여기면 y > 0
```
- **y = TCP − 박스 중심 (벨트 방향, mm). + = TCP 가 하류** (사용자가 본 "앞부분을 잡는다" = y > 0).
- 로그의 `err_along_m` 은 "박스 − TCP" 라 부호가 반대다. 이 문서의 표는 모두 y 로 바꿔 적는다.
- **닫힘 순간** = 핑거가 박스에 닿는 순간 ≈ 닫기 응답 수신(rx) − 0.15 s (2.3절). 명령(cmd)·응답(rx) 시점 값은 괄호로 같이 적는다.
- y_log = 로그(box_tracker 좌표)로 재구성한 값, y_phys = 자로 잰 값.
- (2부 추가) 6.3 에서 접촉 = 명령 + 1.38 s(가설)를 병기한다. 표의 기본 정의는 위 rx − 0.15 그대로.

## 1. 문제

- 현장 관찰(사용자): 모든 실기 시리즈(10/10 s1 FF 4.80, 10/12 s2 4.80, s3 4.73)에서 그리퍼가 박스 앞부분(하류)을 잡는다.
- 허용: 정지 시험에서 ±10 mm 어긋나도 12/12 파지(measurements-1008 #14). **지금 성공률 문제는 아니다.** 여유를 갉아먹는 상수가 있는지, 있다면 무엇인지가 문제다.
- 로그 `err_along` 은 사각에서 FF 로 외삽한 예측 기준이라 실제 어긋남을 못 보여 준다(GRASP 진입 −1.5~−2.0 mm 로 늘 비슷).

## 2. 오프셋 분해 모형

|---|---|---|---|---|

정리하면 **y_phys = e_band + c·Δv + ℓ_k + b₀ + ε**. 로그로 볼 수 있는 부분(①②⑤)과 자로만 볼 수 있는 부분(③④)을 나누는 것이 이 실험의 뼈대다:
**b_phys = y_phys − y_log = ℓ_k + b₀** (회차마다 바로 나온다).

### 2.1 처음 보는 개념
- **최소제곱**: 점들 사이에 "세로 거리 제곱의 합"이 가장 작은 직선을 긋는다. 여기서 점 = (FF 와 박스 속도 차 Δv, y). 기울기 c = "속도 차가 몇 초 동안 쌓였나", 절편 = Δv = 0 일 때 남는 상수.
- **편향 vs 분산**: 분산 = 흩어짐(회차를 늘리면 √n 으로 준다). 편향 = 늘 같은 쪽으로 밀림(회차를 늘려도 안 준다). 박스 속도를 1 % 틀리게 알면 b 가 늘 1.9 mm 밀린다 — 편향이다.
- **식별 가능성**: 자료가 두 원인을 갈라 볼 수 있는가. FF 만 바꾸면 c 는 갈리지만 b 와 "c × 박스 속도" 는 절편 하나로 뭉친다 → 박스 속도를 따로 알아야 b 가 갈린다(4절).
- **정렬 띠 꼬리**: Kp 1.0 /s 이면 오차가 1 초마다 37 % 로 준다. 3 mm 띠 끝에서 DESCEND 를 시작해 0.5 s 뒤 사각에 들어가면 1.85 mm 가 남는다.

## 4. 원인 분리 설계 — 식별 가능성

### 4.1 무엇이 갈리나
- FF(v_FF)는 우리가 정한다 → 회귀 `y = a + c·v_FF` 에서 **c 는 박스 속도를 몰라도 나온다.** 절편 a = b − c·v_박스 이므로 **b 는 박스 속도를 알아야 나온다.**
- 박스 속도 오차 σ_v 가 b 에 더하는 양 = c·σ_v:

| 박스 속도 기준 | σ_v | b 에 더함(c 4.1 s) |
|---|---|---|
| 추종 중 로그 추정(엔코더에 묶임, 3.1) | ≈ 0.25 % (0.12 mm/s) *(추정)* | **≈ 0.5 mm** |
| 손목 카메라 정지 실측 (약 1 % 높게 나옴, FIELD-1012 ⑧) | 1 % (0.47 mm/s) | **≈ 1.9 mm** |

→ 정지 실측은 **변화 감시**용으로만 쓰고, b 계산의 기준은 추종 중 추정값. ⑧ 판단(확신 약 75 %)이 틀렸을 경우를 보이려고 2부에서 b 를 두 기준으로 다 적는다.

- ℓ_k 를 재서 빼면 b₀(핸드아이 + 패드 중심 + 지연) 가 남는다.
- s4b(사다리꼴, 사각 체류 ≈ 1.1~1.3 s)는 같은 FF 에서 체류만 바꿔 Δv 를 카메라 없이 재는 두 번째 길이지만 정밀도 0.7 % 로 기준값보다 나쁘다 → 교차 확인용. 사다리꼴은 가시 DESCEND 시간도 바꿔 ① 꼬리가 달라질 수 있으므로 회차별 제어 예측값을 빼고 비교한다.

### 6.3 자 기울기 3.93 < 로그 4.25 — 접촉 시각 가정으로 설명 가능 (미확정)
