## 0. 먼저 알아 둘 것

### 0.1 개념 — 왜 지금 느린가, 사다리꼴은 무엇인가
```
P 제어 (지금)                          사다리꼴 (이번 단위)
속도 = kp_z × 남은 거리                  속도 = min(최고 속도, √(2 × 감속 × 남은 거리))
  ▲                                      ▲
50│  ┌──┐                               50│  ┌──────┐
  │ /    \__                             │ /        \
  │/        \______  ← 지수 꼬리          │/          \   ← 남은 거리로 딱 멈출 만큼만 감속
 0└──────────────────▶ 2.6 s            0└──────────────▶ 1.6 s
```
- **P 제어의 꼬리**: 남은 거리가 반이 되면 속도도 반이 된다. 그래서 마지막 몇 mm 에서 시간을 다 쓴다(10/12 DESCEND 2.57~2.64 s 중 약 1.9 s 가 꼬리, *(실측·계산)*).
- **감속 거리**: 속도 v 로 가다가 감속 a 로 멈추려면 v²/(2a) 만큼 거리가 필요하다(50 mm/s·0.08 m/s² → 15.6 mm). 사다리꼴은 "지금 멈추기 시작해야 하는 거리"가 될 때까지 최고 속도를 유지한다.
- **지나침(overshoot)**: 로봇은 명령을 조금 늦게(지연) 따라온다. 감속 명령을 늦게 받으면 목표보다 더 내려간다. P 는 끝 속도가 3 mm/s 라 거의 없었지만, 사다리꼴은 목표 근처까지 빠르게 와서(목표에 조준하면 문턱 속도 약 20~27 mm/s, 채택한 (a) 는 5~16 mm/s) 따져야 한다.
- **가속 예산**: `clamp` 는 한 틱(1/30 s)에 속도 벡터가 바뀌는 크기를 max_acc × dt = 3.3 mm/s 로 자른다. 이것은 gateway speedl 램프(acc 100 mm/s²)와 같은 값이다. 로봇이 따라올 수 있는 만큼만 바꾸라는 뜻이다.

## 4. 결정 D4 — 종속 수치 전후표 (close 2.5·x_max 550·margin 10, *(계산)*)

`descend_time_s` 를 프로파일별로 나눈다. 사다리꼴 해석식(조준 거리 S = D − tol, s_a = v²/2a, s_d = v²/2a_dec):
- S ≥ s_a + s_d 이면 T = v/a + v/a_dec + (S − s_a − s_d)/v
- 아니면 v_p = √(S / (1/2a + 1/2a_dec)), T = v_p/a + v_p/a_dec
- 해석값이 sim 보다 0.07~0.1 s 길다(1.70 vs 1.60~1.63) → x 여유·재시도는 보수적이고, 사각·후퇴 상한은 감지가 조금 늦을 뿐이다. 긴 추정이 불안전해지는 용처는 없다(DESCEND 는 x 끝 검사가 따로 잡음, fsm REACH_PHASES — 재검 반박 시도 통과).

## 7. 결정 D7 — z 하한 여유 검사
