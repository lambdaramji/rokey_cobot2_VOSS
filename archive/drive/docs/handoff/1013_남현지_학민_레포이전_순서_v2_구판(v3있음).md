## C. 새 레포로 옮기기 (5분)
**자격 증명 주의:** 공용 PC 는 여럿이 쓴다. 학민 계정 SSH 키·토큰을 공용 PC 에 계속 남기면 다른 사람이 학민 이름으로 push 할 수 있다. HTTPS 로 하고 끝나면 지운다(맨 아래 H).
- push 때 `Username` 은 `rokeyhak`, **`Password` 칸에는 GitHub 비밀번호가 아니라 토큰**을 넣는다(GitHub 는 비밀번호 push 를 받지 않는다). 토큰: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained → Repository access: `rokey_cobot2_VOSS` 만 → Permissions: Contents **Read and write**, Pull requests Read and write → 만료 7일. 토큰은 Slack·파일에 적지 않는다.
```bash
git remote rename origin old-origin                    # 옛 주소는 지우지 않고 보관
git remote set-head old-origin -d                      # old-origin/HEAD 가 'HEAD' 라는 브랜치로 올라가지 않게
git remote add origin https://github.com/rokeyhak/rokey_cobot2_VOSS.git
git push origin refs/remotes/old-origin/main:refs/heads/main     # main = 옛 GitHub main (Username rokeyhak, Password = 토큰)
git push origin 'refs/remotes/old-origin/*:refs/heads/*'         # 옛 GitHub 에 있던 브랜치 전부(팀원 것 포함)
git push origin --tags
git ls-remote origin main                              # c90623f… 로 시작하면 성공
```
Slack 에 "push 완료".
