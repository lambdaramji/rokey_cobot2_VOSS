## 4. 문서와 다르게 한 것 (D7 메모)

- **캘리브레이션 범위**: 관측 자세 화면의 위쪽 절반(상류)은 로봇이 닿지 않습니다 (도달 한계 TCP x ≈ −107). 현장에서 확인한 뒤 9점을 화면 아래 절반(약 13 cm)에만 두었습니다. 위쪽 절반은 외삽입니다. 추종 가능 구간은 TCP x −107 → 638 (약 745 mm).
- **터치 기준점**: `+` 표시 없이 라벨 중앙을 눈으로 맞췄습니다 (±2~3 mm). 그리퍼는 완전히 닫고 OBS 와 같은 수직 자세.
- **위치 표시**: ㄴ자 대신 박스 하류 쪽 변 아래에 이름 테이프 한 조각. C 줄은 벨트 가장자리에 붙여 재현.
- **OBS 복귀 확인**: 터치 후 관절값 MoveJ 로 돌아와 C1 사진과 비교, 어긋남 1~2 px.
- **투입 위치 (NFR-10)**: 벨트 시작점(박스를 올리는 곳)은 로봇 대기 위치(홈)와 겹치지 않습니다.
- **추종 방향(오른쪽) 리치**: 하류 쪽은 TCP x 638 까지 닿습니다 (최대 리치 697 mm). 상류 쪽 한계는 TCP x ≈ −107 입니다.
- **재촬영 필요 후보**: D(조명 변화) bag 이 없습니다. A·C 는 박스 순서 기록이 없어서 bag 별 정답이 필요하면 다시 찍어야 합니다. 그 밖에는 다시 찍을 것이 없습니다.
- **생략**: D(조명 변화), E(하강). 흐린 송장은 번짐이 약하게 인쇄됐습니다.
- **정지 송장 회전**: 회전 6장, 일부는 약 30° (문서의 10°보다 큼).
- **박스 파지**: 31 mm 면을 쥡니다. 46 mm 변이 벨트 방향.

### 캘리브레이션할 때 주의: 플랜지 기준과 TCP 기준

- **펜던트 값, points.csv, 이 문서의 D1** 은 **TCP 기준**입니다. TCP는 핑거 끝이고, 펜던트 TCP 설정은 `(1.382, 2.684, 246.642, 0, 0, 0)` 입니다.
- **voss_config.yaml** 의 `zones`, `observe_pose` 는 **플랜지 기준**입니다. 플랜지는 로봇 손목 끝이고, TCP 를 적용하지 않은 값입니다.
- 그리퍼가 아래를 향하면 플랜지 z ≈ TCP z + 246.6 mm 입니다. 예를 들어 관측 자세는 TCP z 203.58 이고, 플랜지 z 는 450.16 입니다.
- 핸드아이 결과를 config 좌표와 함께 쓸 때 두 기준을 섞지 않도록 주의해 주세요.

### 구역 격자 변경

- 구역마다 트레이를 두었습니다. 트레이 안쪽 바닥은 215 × 145 mm, 바닥 두께는 5 mm, 벽 높이는 40 mm 입니다. 트레이는 긴 변이 벨트 방향(X)이 되도록 놓았습니다.
- 격자는 **X 방향 한 줄**입니다. A·B·C 는 3×1 (중심 기준 X −60 / 0 / +60), 재확인·보류는 2×1 (X ±30), 칸 간격은 60 mm 입니다. 전체 13칸으로 시연 박스 10개를 놓습니다.
- Y 방향으로 칸을 두면 90 mm 로 벌린 핑거가 트레이 벽에 가까워집니다. 그래서 X 방향으로만 칸을 둡니다.
