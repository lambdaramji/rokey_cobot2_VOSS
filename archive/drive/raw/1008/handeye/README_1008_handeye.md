## 조건
- 보드: 11×8칸, 내부 코너 10×7, 칸 25.0 mm (실측 가로 275 mm/11칸, 세로 200 mm/8칸), 도마에 붙여 벨트 하류 레일 위에 고정
- 보드 중심(대략, base) (314, -286, 103) mm
- 카메라: D435i 1920×1080 rgb8, 노출 60(6 ms), WB 4600 고정, camera_info K 는 공장값·d=0
- 로봇 pose: `/voss/robot/pose` (TCP, tcp_offset [1.382, 2.684, 246.642] = 펜던트 GripperDA_v1), 0.5 초 평균, 정지 판정 통과
- 기준 자세(REF) posx [395.54, -276.51, 283.54, 84.86, -179.09, -6.43]

## 문서와 다르게 한 것
- 직접교시는 펜던트 강제 회수가 필요해서 안 함 → move_line ASYNC 로 자세 이동, 매 자세 Enter 로 사람이 승인, 멈추면 자동 촬영
  (두산 서비스를 게이트웨이 밖에서 직접 호출 — 규칙 3 예외)
- 2차는 1차 6장으로 대략 푼 T_tcp_camera 로 "카메라가 보드 중심을 보게" 자세를 짜고, motion/ikin 으로 도달 가능 여부를 미리 확인
- 공구축 회전 ±60° 는 보드가 화면 밖으로 나가서 ±30/±15 로 줄임, 기울기 10~25° (사진 쌍 회전 차이 중앙값 33°, 최대 72°)
- 바깥쪽 기울임은 NOT REACHABLE(알람 1206): J5 134° 도달, 152° 거부 → J5 > 140° 자세는 계획에서 제외
